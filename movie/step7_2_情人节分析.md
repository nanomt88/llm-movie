## 情人节用户观影数据统计

@movie/step5_genre.py 根据代码中生成的数据，检查为什么 情人节当天，系统给观影人推荐的电影类型中不是爱情片占比最多？ 是代码有bug统计错误，还是结果就是这样，或则统计口径有误

---

### 真实数据（情人节 4 天，2019–2022）

| 指标 | 数值 |
|---|---|
| 情人节用户提问数 | 1507 条 |
| 系统推荐的不同电影数 | 1573 部 |
| 其中爱情片 | 239 部（**15.2%**） |
| 其中剧情片 | 819 部（**52.1%**） |
| 剧情日均提及 | 919/4 = **229.75** |
| 爱情日均提及 | 277/4 = **69.25**（排第 9） |

### 为什么不是爱情片最多

1. **每部电影有多个类型**：一部电影通常带 2–5 个类型，每个类型都会被计入 counter。剧情作为"基础类型"出现得极频繁。
2. **movie_info.json 全库本身的偏置**：剧情占 **49.6%**，爱情仅占 **14.6%**。在累加式计数下，剧情天然压倒一切。
3. **推荐系统并未按节假日过滤**：情人节会话里的系统回复就是普通推荐，爱情片占比 15.2% 与全库 14.6% 基本一致——**情人节根本没多推荐爱情片**。
4. **J3 差值图也佐证**：情人节的爱情日均值 69.25，反而比非节假日基线 97.43 **更低**（绝对值降 28.18，相对降 28.9%，是所有类型里降幅最大的）；爱情占情人节总提及的 5.4%，还低于基线 6.0%。

所以用户看到"情人节爱情片不是第一"是数据的真实反映，不是统计错误。

### 想让"情人节效应"显出来该怎么办

当前累加计数法无法体现节假日的类型偏好。正确做法是看**相对基线的份额/比值**（即 J3 差值矩阵）——但即便如此，情人节的爱情份额反而比基线低，结论会更反直觉。若想验证"情人节推荐爱情片是否升高"，需对照同长度时间窗的非节假日，看 Romance 占比的相对变化，而非绝对计数。

# 情人节对比 方案

。若想验证"情人节推荐爱情片是否升高"，需对照同长度时间窗的非节假日，看 Romance 占比的相对变化，而非绝对计数。 

给出这个验证的思路和过程，不用给出执行结果，执行结果太慢了


## 验证思路

当前 step5 用的是"绝对计数 + 多类型累加"，必然被 Drama 主导。要回答"情人节是否多推荐了爱情片"，需要换成**相对份额**对比，且对照窗口要**同时段同长度**以消除季节性和总量差异。

核心改造有三点：
1. **指标改用份额**：`share = romance_mentions / total_genre_mentions`，或更稳健的"提及爱情片的记录占比"。
2. **构造匹配的对照窗口**：对照窗口需与情人节同期、同长度、非节假日，避免春节、超级碗等邻近假日干扰。
3. **做统计检验**：份额差值要配比例检验（卡方/Fisher），不能只看绝对差。

## 验证过程

### 1. 定义实验组与对照组

**实验组（Valentine）**：`{'2019-02-14','2020-02-14','2021-02-14','2022-02-14'}`，共 4 天。

**对照组（Control）**：每年取**情人节前 7 天 + 后 7 天**中的非节假日日期（剔除 2/14 本身、超级碗周日、春节、总统日），按年配对，4 年合计应接近 4 天的倍数（即对照窗口长度 = 实验组长度，可做逐年配对比较）。

> 也可用"同年同月非节假日"作为更宽松的对照；用 ±7 天窗口更严，能控制月度趋势。

### 2. 复用现有提取逻辑

调用 `movie.utils.text.build_conv_system(rows)` + `get_system_movie_ids(conv_id, conv_system)` 拿到每条 seeker 对应系统回复中的电影 ID 集合（与 step5 完全一致的口径，不重复实现）。

### 3. 为每条 seeker 计算三个指标

```python
for r in seekers:
    mids = get_system_movie_ids(r['conv_id'], conv_system)
    genres = set()
    for mid in mids:
        info = movie_info.get(mid, {})
        genres.update(info.get('genres', []) or [])   # 中文也行，只判 '爱情' in set
    r['has_romance'] = '爱情' in genres if mids else None   # None 表示无系统回复，排除
    r['n_genres']    = len(genres)
    r['romance_in_set'] = int(r['has_romance'] is True)
```

### 4. 按日期聚合得到日级份额

对实验组和对照组分别计算**每天**的：
- `romance_share_count`  = `romance_mentions / total_genre_mentions`（沿用 step5 计数口径，只是看份额）
- `romance_share_records` = `records_with_romance / records_with_any_movie`（**推荐用这个**，规避多类型累加偏置）
- `total_records`         = 当日有系统回复电影的总提问数

### 5. 多年配对 + 显著性检验

按年配对（每年情人节 vs 同年对照窗口），避免不同年份总量差异污染：

```text
2019: val_share   vs   ctrl_share_2019
2020: val_share   vs   ctrl_share_2020
2021: val_share   vs   ctrl_share_2021
2022: val_share   vs   ctrl_share_2022
```

检验方法：
- **比例检验（推荐）**：把 4 年汇总成 2×2 列联表（行=Valentine/Control，列=有爱情片记录/无爱情片记录），用 `scipy.stats.chi2_contingency` 或 Fisher exact。p<0.05 才支持"情人节显著多推荐爱情片"。
- **逐年差值**：每年算 `delta = val_share - ctrl_share`，看符号是否一致、量级是否稳定。
- **效应量**：Cohen's h 或相对风险 RR = val_share / ctrl_share，给"高出多少倍"一个可解读的数。

### 6. 判断标准

- 若 RR ≈ 1 且 p > 0.05：结论 = **情人节没有显著多推荐爱情片**（当前 J5/J3 数据指向这个）。
- 若 RR > 1.5 且 p < 0.05：结论 = 情人节确实有偏好，原 step5 的绝对计数只是被 Drama 体量盖住了。
- 还需检查：把"超级碗周日 / 总统日"等同时段节假日也跑一遍作 sanity check，确认情人节不是被这些邻近节假日拖低。

### 7. 关键陷阱提醒

- **不要用绝对计数比**：情人节总提问量本就低于基线（1280.5 vs 1610.3），绝对数低不等于份额低。
- **必须排除"无系统回复电影"的记录**：否则分母会被空回复稀释。
- **多类型不重复计**：用 `has_romance`（布尔）比 `romance_count`（每个电影多类型）稳健，避免一部爱情剧情片同时给 Drama 和 Romance 各加 1 的双重膨胀。
- **同长度窗口**：对照窗口天数要等于实验组（4 天）或为其整数倍，否则日均值不可比。
- **多年配对**：不要简单把 4 年情人节的天数加起来除总数，要先按年算每年的份额，再对 4 个年度份额求均值/做检验，否则大年份（如 2020 提问量 2267）会主导结果。

### 8. 输出建议

输出一张表：

|---|---|---|---|---|---|
| 2019 | … | … | … | … | … |
| … | | | | | |
| 汇总 | … | … | … | … | … |

## 详细分析结果

## 一、运行概况

| 指标 | 值 |
|---|---|
| 数据范围 | 2019–2022，2 月内全部记录 |
| 实验组（情人节）样本 | **1,479** 条 seeker（系统回复中含电影 ID 的） |
| 对照组（±14 天非节假日）样本 | **36,076** 条 seeker |
| 系统回复无电影的记录 | 已剔除（无法判定类型） |
| 运行耗时 | ~90 秒（数据加载占 70%） |

## 二、核心结论

> **情人节当天系统推荐的"含爱情片"比例反而显著低于同期非节假日窗口**（Δ = −2.52pp，p = 0.022）

| 统计量 | 值 | 解读 |
|---|---|---|
| Valentine share | **18.73%** | 情人节每条提问推荐的电影中，含爱情片的占 18.73% |
| Control share | **21.25%** | 对照窗口同一比例为 21.25% |
| **Δ = V − C** | **−0.0252** | 情人节反而**低 2.5 个百分点** |
| **RR** | 0.88 | 情人节推荐爱情片的概率是对照的 0.88 倍 |
| **Cohen's h** | −0.063 | 效应量**极小**（<0.20 的"小效应"门槛） |
| χ² | 5.26 | p(χ²) = 0.0218 |
| Fisher exact | OR=0.854 | p(Fisher) = 0.0194 |

**统计判定**：`p < 0.05 且 Δ < 0` → **情人节推荐爱情片显著更少**。

## 三、逐年拆解（关键发现）

| 年份 | Valentine share | Control share | Δ | Valentine n | 说明 |
|---|---|---|---|---|---|
| 2019 | 0.1398 | 0.2201 | **−0.080** | 279 | 情人节远低于对照 |
| 2020 | 0.1711 | 0.2194 | **−0.048** | 643 | 仍低于对照 |
| 2021 | 0.1922 | 0.2103 | −0.018 | 307 | 基本持平 |
| 2022 | **0.2760** | 0.1980 | **+0.078** | 250 | 反向：情人节更高 |

**关键观察**：
1. **方向不一致**：4 年里 3 年情人节更低、1 年（2022）反而更高。统计显著性主要由 2019、2020 拉动。
2. **2022 异常**：情人节份额飙到 0.276，但样本量最小（n=250，仅 69 条含爱情片），95% CI 误差棒最大（图上看约 ±0.06），不确定性高。
3. **对照组极稳定**：4 年 Control share 在 0.198–0.220 之间窄幅波动，说明推荐系统有一个稳定的爱情片基线率（约 21%），情人节并没有明显抬升它。
4. **样本量悬殊**：对照组总量是实验组的 24 倍，χ² 的显著性主要来自大样本对微小差异的放大。

## 四、对原 step5 结论的修正

原 step5（J5 CSV）：
- 情人节爱情片**日均绝对计数** = 69.25（排第 9）
- 非节假日基线 = 97.43
- 看起来"情人节爱情片少"——这个观察**方向正确**

但当时无法判断这是否只是"情人节总量低"的副作用（情人节日均总提问 1280.5 vs 基线 1610.3）。本步骤用**份额**指标剥离了总量影响：
- 剥离后情人节爱情片**份额仍显著更低**（18.73% vs 21.25%）
- 即便如此，**绝对差距仅 2.5pp，Cohen's h 仅 0.063**，实际意义非常有限

## 五、解释：为什么情人节反而推荐更少爱情片？

1. **推荐系统对日期不敏感**：系统基于用户提问内容推荐电影，不知道"今天是情人节"。
2. **用户提问多样化**：情人节用户问的不一定是爱情片——可能是约会看的喜剧、剧情、惊悚片（约会片≠爱情片）。
3. **基线已经偏高**：全库 14.6% 的电影是爱情片，对照窗口 21% 的记录推荐过爱情片——这已经包含了所有日常的推荐量。情人节没有额外加成。
4. **2022 异常可能纯属小样本噪声**：n=250 的二项分布 95% CI 约 ±5.6pp，0.276 的点估计完全可能与基线 0.21 相容。

## 六、方法学回顾与局限

| 设计点 | 实现情况 | 评估 |
|---|---|---|
| 指标用份额而非绝对计数 | ✅ 用 has_romance 布尔 | 修正了 step5 的多类型累加偏置 |
| 同长度同时段对照窗口 | ✅ 同年 ±14 天非节假日 | 控制了季节性与年度趋势 |
| 排除邻近节假日干扰 | ✅ 通过 `period != 'holiday'` 自动排除总统日、超级碗、春节 | 干净的对照 |
| 多年配对 + 汇总检验 | ✅ 逐年表 + 汇总 χ²/Fisher | 兼顾稳定性与统计力 |
| 效应量报告 | ✅ Cohen's h + RR | 避免"显著但无意义"误读 |
| 误差棒 | ✅ 95% CI = 1.96·√(p(1-p)/n) | 暴露小样本不确定性 |

**局限**：
- 实验组每年仅 1 天，情人节 n=250–643，对年度内异常事件敏感
- 仅测了"是否含爱情片"二值指标，未测爱情片在推荐列表中的**排名/数量**
- 未控制用户群体特征（年龄段、活跃度）——若情人节提问用户群体与平时不同，可能引入混杂

## 七、最终判定

**回答用户原始问题**：
- 不是代码 bug，统计口径正确 ✅
- 情人节推荐爱情片**确实不是最多**——剧情片（52.1%的电影带剧情类型）压倒性占优 ✅
- 进一步用份额验证后发现：**情人节推荐爱情片的比例不仅没升高，反而比同期非节假日低 2.5pp**（p=0.022），但效应量极小（Cohen's h=0.063），且 2022 年出现反向，结论在统计上显著但实际意义有限 ✅
