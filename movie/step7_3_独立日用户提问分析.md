提问：在以上分析基础上，增加一组数据分析，对独立日用户提问内容进行分析，验证用户是否比其他时间对爱国电影的需求有增加？ 给出详细分析结果

## 九、最终判定（结合系统侧 + 用户侧）

### 回答用户原始问题

**美国独立日（7/4）期间，观影人没有比其他时间对爱国电影的需求增加。** ✅ 强结论

### 证据链（7 个定义全景）

1. **系统侧 5 个定义全部 p > 0.05**：推荐系统不会在 7/4 多推荐爱国片

3. **用户侧 F 定义 p=0.0002（显著更少）**：但**受 "truman" 假阳性驱动**，排除后显著性大幅减弱

### 柱状图上的两个线段（误差线）
这是 **95% 置信区间（95% Confidence Interval）** 的误差线，由以下公式计算（第 721–722 行）：

```
误差 = 1.96 × √(p × (1 - p) / n)
```


其中：
- `p` = 该组的 `patriotic_share`（样本比例）
- `n` = 该组的记录数（`n_records`）
- `1.96` 是正态分布 95% 置信水平的 Z 值

**含义**：每个柱子上方的 "工" 字形线段表示该比例的**真实值有 95% 的概率落在该区间内**。线段越长说明样本量越小、不确定性越大；线段越短说明估计越精确。

### 标题中的统计量

以左图（定义 F）为例：`Δ=-0.0198, RR=0.58, p(χ²)=0.0002, p(F)=0.0001, h=-0.106`

| 标记 | 含义 |
|------|------|
| **Δ** (`delta_share`) | 独立日份额 − 对照组份额，负值表示独立日反而更低 |
| **RR** (`relative_risk`) | 相对风险 = 独立日份额 / 对照组份额，<1 表示独立日更低 |
| **p(χ²)** | Pearson 卡方检验的 p 值，<0.05 表示差异显著 |
| **p(F)** | Fisher 精确检验的 p 值，更稳健的小样本检验 |
| **h** | Cohen's h 效应量，衡量差异的实际大小（绝对值 >0.2 为小效应） |

### 四个统计指标的含义与计算规则

这四个指标都在 [_pooled_stats](file://D:\workspaces\python\llm-movie\movie\step7_3_independence.py#L418-L465) 函数中计算，基于**汇总全部4年**的 2×2 列联表。

#### 共同的统计口径

2×2 列联表（[第431-434行](file://D:\workspaces\python\llm-movie\movie\step7_3_independence.py#L431-L434)）：

|                      | 命中爱国电影 | 未命中爱国电影    | 合计     |
| -------------------- | ------------ | ----------------- | -------- |
| **独立日（实验组）** | `val_r`      | `val_n − val_r`   | `val_n`  |
| **对照组**           | `ctrl_r`     | `ctrl_n − ctrl_r` | `ctrl_n` |

- **`val_r`**：独立日当天、系统回复中"至少推荐一部命中该定义电影"的记录数
- **`val_n`**：独立日当天所有有效记录总数
- **`ctrl_r` / `ctrl_n`**：对照组对应值
- **份额**：`val_share = val_r / val_n`，`ctrl_share = ctrl_r / ctrl_n`

---

#### 1. RR（相对风险 / Relative Risk）

**含义**：独立日推荐爱国电影的份额是对照组的多少倍。

**计算规则**（[第449行](file://D:\workspaces\python\llm-movie\movie\step7_3_independence.py#L449)）：

```python
rr = val_share / ctrl_share if ctrl_share > 0 else float('inf')
```



即 **RR = 独立日份额 / 对照组份额**

**解读**：

- RR > 1：独立日推荐爱国电影的比例更高
- RR < 1：独立日推荐爱国电影的比例更低
- RR = 1：两组无差异
- 当对照组份额为0时，RR = ∞（无穷大）

---

#### 2. p(χ²)（Pearson 卡方检验 p 值）

**含义**：Pearson 卡方检验的显著性 p 值，判断独立日与"是否推荐爱国电影"的关联是否统计显著。

**计算规则**（[第438行](file://D:\workspaces\python\llm-movie\movie\step7_3_independence.py#L438)）：

```python
chi2, p_chi2, dof, expected = stats.chi2_contingency(table)
```

- 使用 `scipy.stats.chi2_contingency`，**默认带 Yates 连续性修正**
- 输入为上述 2×2 列联表
- 返回：卡方统计量 `chi2`、p 值 `p_chi2`、自由度 `dof`、期望频数 `expected`

**解读**：

- p < 0.05：关联显著（独立日与爱国电影推荐存在统计学关联）
- p ≥ 0.05：无显著关联

**注意**：卡方检验在期望频数较小时（如某格 <5）可能不够准确，此时看 Fisher 检验更可靠。

---

#### 3. p(F)（Fisher 精确检验 p 值）

**含义**：Fisher 精确检验的 p 值，是卡方检验在小样本下的精确替代方案。

**计算规则**（[第439行](file://D:\workspaces\python\llm-movie\movie\step7_3_independence.py#L439)）：

```python
odds_ratio, p_fisher = stats.fisher_exact(table, alternative='two-sided')
```

- 使用 `scipy.stats.fisher_exact`，**双侧检验**（`alternative='two-sided'`）
- 输入为同一 2×2 列联表
- 返回：优势比 `odds_ratio`、p 值 `p_fisher`

**解读**：

- p < 0.05：两组差异显著
- p ≥ 0.05：无显著差异
- Fisher 检验基于超几何分布计算精确概率，不依赖大样本近似，**在小样本下比卡方更可靠**

---

#### 4. h（Cohen's h 效应量）

**含义**：Cohen's h 是基于角度转换的效应量指标，衡量两组份额差异的大小，与样本量无关。

**计算规则**（[第444-446行](file://D:\workspaces\python\llm-movie\movie\step7_3_independence.py#L444-L446)）：

```python
def _phi(p):
    return 2.0 * np.arcsin(np.sqrt(np.clip(p, 0.0, 1.0)))
h = _phi(val_share) - _phi(ctrl_share)
```


即 **h = φ(独立日份额) − φ(对照组份额)**，其中 φ(p) = 2·arcsin(√p)

**解读**（Cohen 的经验标准）：

- |h| ≈ 0.20：小效应
- |h| ≈ 0.50：中等效应
- |h| ≈ 0.80：大效应

**优势**：经过 arcsin√p 转换后方差稳定，不受份额接近0或1时的影响，适合比较不同定义间的效应大小。
