**脚本文件:** `movie/step7_word_independence_3.py`
**创建日期:** 2026/7/20
**输出目录:** `output/movie/step7/`

## 一、分析背景与问题

延续情人节分析的思路（`step7_2_情人节分析.md`），本步骤将同样的"份额对比 + 统计检验"方法论应用于**美国独立日（7 月 4 日）**，验证以下问题：

> 独立日当天，系统推荐的电影中是否显著包含更多"爱国主题"电影？用户提问中是否体现了更多爱国兴趣？

与情人节分析不同，"爱国主题电影"没有单一的 genre 标签可用（不像"爱情"对应 `genres` 中的"爱情"字段），因此本步骤设计了**5 层系统侧定义 + 2 层用户侧定义**的多维度分类器来界定"爱国电影"。

## 二、数据分析思路

### 2.1 统计口径

| 维度 | 定义 |
|---|---|
| **实验组（Independence）** | 2019–2022 共 4 个独立日：`{'2019-07-04','2020-07-04','2021-07-04','2022-07-04'}` |
| **对照组（Control）** | 同年 7 月内、距 7/4 ±14 天、`period ∈ {workday, weekend}` 的非节假日日期（排除所有 `period == 'holiday'` 的其他节假日） |
| **对照窗口半径** | ±14 天（`CONTROL_WINDOW_DAYS = 14`） |
| **主指标** | `patriotic_share = 含爱国片记录数 / 总有效记录数`（份额，非绝对计数） |
| **记录粒度** | 每条用户提问（seeker）记录 = 1 个样本 |
| **排除规则** | 系统回复无电影 ID 的记录全部剔除（无法判定类型） |

### 2.2 统计规则

#### 系统侧 5 层爱国分类器（A–E）

对每部电影，预计算其在 5 个定义下的命中情况：

| 定义 | 名称 | 判定逻辑 |
|---|---|---|
| **A** | 关键词命中（扩充版） | `title + original_title + overview` 拼接后转小写，检查是否包含任一中英文爱国关键词（~120 个，涵盖独立/解放、总统名、美国象征、历史事件、军事术语等） |
| **B** | 体裁代用品 | `genres ∈ {战争, 历史}`（中文 genre 名） |
| **C** | A ∪ B 联合 | A 或 B 任一命中（最大召回） |
| **D** | B + 美国产地 | B 命中 **且** `country` 含 `"United States of America"` |
| **E** | 精选 116 部清单 | 电影 IMDB ID 在人工策展的 116 部美国爱国电影集合中（含《独立日》《拯救大兵瑞恩》《林肯》《壮志凌云》《美国狙击手》等） |

#### 用户侧 2 层定义（F–G）

| 定义 | 名称 | 判定逻辑 |
|---|---|---|
| **F** | 用户提问含爱国关键词 | 用户提问原文（`raw_text`，英文）转小写后包含任一英文爱国关键词 |
| **G** | 用户提问提及精选爱国电影 | 用户提问中的 IMDB ID（`imdb_ids` 字段或正则从 `proc_text` 提取）与 116 部精选集合有交集 |

#### 记录级判定规则

- **系统侧**：一条 seeker 记录对应多个系统推荐电影 ID，只要其中**至少一部**命中某定义，该记录在该定义下标记为 `True`（布尔值，非计数，避免多类型累加偏置）
- **用户侧**：直接检查用户提问文本/提问中提及的电影 ID

### 2.3 统计及计算步骤

#### 步骤 1：构建爱国电影索引

```python
patriotic_index = _build_patriotic_index(movie_info)
# 对 movie_info.json 中每部电影，预计算 {A:bool, B:bool, C:bool, D:bool, E:bool}
```

遍历全部 49,015 部电影，对每部按 5 个定义分别判定，结果缓存为 `dict[mid -> {A,B,C,D,E}]`。

#### 步骤 2：聚合记录

```python
records = _aggregate_records(seekers, conv_system, patriotic_index)
```

对每条 seeker 记录：
1. 解析日期，过滤非 7 月数据
2. 分组判定：独立日当天 → Independence；±14 天内 workday/weekend → Control；其余排除
3. 调用 `get_system_movie_ids(conv_id, conv_system)` 提取系统回复中的电影 ID 集合
4. 系统回复无电影 → 剔除
5. 对 5 个定义分别判定：该记录推荐的电影中是否至少一部命中 → `has_A` ~ `has_E`

#### 步骤 3：逐年聚合统计

```python
per_year_by_def = {k: _per_year_stats(records, f'has_{k}') for k in DEFINITIONS}
```

按 `(year, group)` 分组，计算：
- `n_records`：总有效记录数
- `n_patriotic`：含爱国片记录数
- `patriotic_share = n_patriotic / n_records`

#### 步骤 4：汇总统计 + 显著性检验

```python
pooled_by_def = {k: _pooled_stats(records, f'has_{k}') for k in DEFINITIONS}
```

汇总全部年份，构建 2×2 列联表：

| | 含爱国片 | 不含爱国片 |
|---|---|---|
| Independence | val_r | val_n - val_r |
| Control | ctrl_r | ctrl_n - ctrl_r |

执行以下检验：
- **Pearson χ² 检验**（`scipy.stats.chi2_contingency`，默认带 Yates 连续性修正）
- **Fisher 精确检验**（`scipy.stats.fisher_exact`，双侧）
- **Cohen's h** 效应量：`h = 2·arcsin(√p_val) - 2·arcsin(√p_ctrl)`
- **相对风险 RR**：`RR = val_share / ctrl_share`
- **Δ 份额差**：`Δ = val_share - ctrl_share`

#### 步骤 5：用户侧分析

对用户提问执行类似的聚合 + 检验流程（定义 F/G），并额外输出 top-30 关键词频率对比（按 Independence/Control 份额比降序排列）。

#### 步骤 6：Top-N 电影清单

- 7/4 当天推荐最多的 top-30 电影（含各定义命中标记），用于人工核查
- 7/4 当天定义 D 命中的 top-10 美国战争/历史片

#### 步骤 7：综合判定

对 5 个系统侧定义分别判定符号：
- `p < 0.05 且 Δ > 0` → `+`（独立日显著更多爱国片）
- `p < 0.05 且 Δ < 0` → `−`（独立日显著更少爱国片）
- 其余 → `0`（无显著差异）

根据 5 个定义的符号一致性给出最终结论。

## 四、解释：为什么独立日没有推荐更多爱国片？

1. **推荐系统对日期不敏感**：系统基于用户提问内容推荐电影，不知道"今天是独立日"。
2. **用户提问多样化**：独立日用户问的以恐怖片、喜剧片为主（Top-30 排行佐证），而非爱国主题电影。
3. **爱国电影全库占比本就低**：精选 116 部仅占全库 0.24%，战争/历史 genre 占 ~7%，基线份额已经很低。
4. **用户侧爱国关键词提问反而更少**：定义 F 显示独立日爱国关键词提问份额 2.74% < 对照 4.72%，可能因为独立日用户更关注娱乐性内容而非严肃话题。
5. **样本量小**：独立日每年仅 1 天，实验组总量 1,616 条，对年度内异常事件敏感。

## 五、方法学回顾与局限

| 设计点 | 实现情况 | 评估 |
|---|---|---|
| 指标用份额而非绝对计数 | ✅ 用布尔值（has_patriotic） | 修正了多类型累加偏置 |
| 同长度同时段对照窗口 | ✅ 同年 ±14 天非节假日 | 控制了季节性与年度趋势 |
| 排除邻近节假日干扰 | ✅ 通过 `period != 'holiday'` 排除 | 干净的对照 |
| 多定义交叉验证 | ✅ 5 个系统侧 + 2 个用户侧定义 | 结论稳健性强 |
| 效应量报告 | ✅ Cohen's h + RR | 避免"显著但无意义"误读 |
| 误差棒 | ✅ 95% CI = 1.96·√(p(1-p)/n) | 暴露小样本不确定性 |
| 精选清单人工策展 | ✅ 116 部知名美国爱国电影 | 最精准但召回有限 |

**局限**：
- 实验组每年仅 1 天，独立日 n=97–870，对年度内异常事件敏感
- "爱国电影"定义本身有主观性——5 个定义各有偏向：A 召回高但噪声大、E 精准但覆盖窄
- 未控制用户群体特征（年龄段、活跃度）
- 对照组样本量是实验组的 ~21 倍，χ² 对微小差异的敏感度受样本量影响

## 六、最终判定

**回答原始问题**：

1. **系统推荐侧**：独立日当天系统推荐的电影中，爱国主题电影比例**与同期非节假日无显著差异**（5 个定义全部 p > 0.05）。定义 D（美国战争/历史片）虽然 Δ 为正（+0.7pp），但未达统计显著。✅

2. **用户提问侧**：定义 F 显示独立日用户提问中爱国关键词比例**反而显著更低**（Δ=−2.0pp，p=0.0002，RR=0.58），但效应量小（Cohen's h=−0.106），且主要由 2020–2021 年驱动，方向不稳定。✅

3. **综合结论**：独立日既未在系统推荐中体现爱国偏好，也未在用户提问中体现更多爱国兴趣。推荐系统的行为完全由用户提问内容驱动，与节假日主题无关联。✅
